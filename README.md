# Django ChatOps 

A **Django-based real-time chat application** built with a focus on modern **Cloud and DevOps technologies**.

This project is being developed as a practical application to understand how a web application can be **containerized, automated, deployed, and managed in a production-like environment**.

##  Technologies Used

* **Python**
* **Django**
* **HTML / CSS**
* **Git**
* **GitHub**
* **Docker**
* **GitHub Actions**
* **Kubernetes**
* **Kubernetes Auto-Healing**
* **Liveness & Readiness Probes**
* **Horizontal Pod Autoscaling (HPA)**
* **Monitoring & Logging**
* **Cloud Deployment**

## ☁️ DevOps Focus

The application is designed to be integrated with a complete DevOps workflow:

**GitHub → CI/CD → Docker → Kubernetes → Auto-Healing → Auto-Scaling → Monitoring → Cloud**

The goal is to gain hands-on experience with deploying and managing a Django application using modern **Cloud and DevOps practices**.

## Project Goal

To build a functional Django chat application and gradually transform it into a **containerized, automated, scalable, and highly available application** using Cloud and DevOps technologies.
